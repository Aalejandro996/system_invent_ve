1) PostgreSQL:   createdb sistema_ve
2) Dependencias: pip install -r requirements.txt
3) Variables:    export DATABASE_URL="postgresql://USUARIO:CLAVE@localhost:5432/sistema_ve"
                 export SECRET_KEY="$(python -c 'import secrets;print(secrets.token_hex(32))')"
4) Desarrollo:   python app.py   (imprime las claves iniciales de admin / inventario / usuarios)
5) Producción (HTTPS):
   export APP_ENV=production
   gunicorn -w 3 -b 127.0.0.1:8000 app:app
   Nginx con TLS: deploy/nginx.conf + certbot. La app redirige a https, activa cookies Secure y HSTS.
6) Admin > ISLR/IGTF: cargue los conceptos de retención ISLR con los porcentajes vigentes.
Respalde la base con pg_dump periódicamente.

USUARIOS BASE: admin, inventario, usuarios
 - Sus claves se generan al azar la primera vez que arranca la app y se imprimen en consola.
 - Para fijarlas usted:  export PASS_ADMIN=... PASS_INVENTARIO=... PASS_USUARIOS=...   (antes del primer arranque)
 - Para regenerarlas / recuperarlas:  python app.py --reset-claves   (imprime usuario / clave nuevos)

DEMO EN RENDER
 1) Suba la carpeta a un repositorio de GitHub (app.py, requirements.txt, render.yaml, .gitignore).
 2) Render > New > Blueprint > elija el repositorio. Crea la base de datos y el servicio web.
 3) Al terminar el despliegue, abra la URL https://sistema-ve-demo.onrender.com (o la que asigne Render).
 4) Las claves de admin / inventario / usuarios están en Render > servicio > Environment (PASS_ADMIN, etc.).
 5) Reiniciar los datos de ejemplo: Render > servicio > Shell:  python app.py --reset-demo
Con DEMO_MODE=1: banner de demostración, datos ficticios precargados, y bloqueados el cambio de claves y la edición de usuarios base.

BASE EXISTENTE EN RENDER (el plan gratuito permite una sola base activa)
 - render.yaml ya no crea base de datos: en DATABASE_URL pegue la "Internal Database URL" de la base que ya tiene
   (Render > Postgres > Connect). La app crea su propio esquema "sistema_ve" y no toca otras tablas.
 - La base y el servicio web deben estar en la misma región; si no, use la "External Database URL".

MÓDULOS DE FINCA 
 Roles nuevos: "finca" (ganado y operaciones) y "personal" (puestos y asistencia); el admin ve todo. Se crean desde el usuario "usuarios".
 Módulos: Ganado, Potreros (localización), Pesajes, Traslados (interno / transporte externo / transbordo, con placa, chofer y guía),
 Sanidad y vacunación (con próxima aplicación y alertas), Insumos, Alimentación (descuenta existencia), Entradas de insumos,
 Reproducción, Puestos, Empleados y Asistencia (marcar llegada/salida; reporte de tardanzas y horas).
 Todas las listas se exportan a Excel; también los libros de compras/ventas y los listados de compras y ventas.
 Las tablas se crean solas al arrancar (prefijo f_). Para agregar otro módulo, añada una entrada en ENT dentro de app.py (sección "Módulos de finca").
IMPORTAR FACTURAS: Compras/Ventas > Importar factura (PDF o imagen). Requiere la variable ANTHROPIC_API_KEY; opcional ANTHROPIC_MODEL.
 El sistema interpreta el documento, muestra el formulario lleno y usted corrige y guarda. El archivo no se almacena.

INTEGRACIÓN FINCA + INVENTARIO + COMPRAS/VENTAS (un solo sistema)
 - Inventario único: los alimentos, sales, medicinas y demás insumos son PRODUCTOS con categoría (General, Alimento, Mineral/Sal,
   Medicina, Combustible, Insumo, Ganado, Servicio). "Ganado" y "Servicio" no llevan existencia. Ya no hay módulo de insumos aparte:
   las compras de insumos entran al inventario con la factura de compra.
 - Alimentación y Sanidad descuentan del inventario general (con su movimiento y costo automático) y avisan si falta existencia.
 - Venta de ganado: en Ventas > Registrar, use el producto "Ganado en pie" (cantidad = cabezas) y seleccione los animales en
   "Ganado vendido": al guardar pasan a Vendido. La cantidad facturada debe coincidir con los animales elegidos.
 - Compra de ganado: use el mismo producto y escriba los aretes en "Ganado comprado": entran al hato como Activos.
 - Traslados tienen "Nº factura asociada" para ligar el transporte con la venta.
 - Panel general (admin): ventas y compras del mes, por cobrar/pagar, inventario valorizado, cabezas, costo de alimentación y sanitario.
 - Menú agrupado: Panel, Comercial, Inventario, Finca, Personal. Cada rol ve solo su grupo.
 - Las alícuotas de IVA de los productos de ejemplo (alimentos, ganado) son ilustrativas: ajústelas con su contador.
